# HomePlate — "Hearth" Prototype

> BUS146 Final Project — Viable Venture

A clickable prototype for **HomePlate**, an "Etsy for Homemade Food" peer-to-peer marketplace connecting local home cooks with nearby customers who want fresh, authentic, home-cooked meals.

## Brand Direction

**Hearth** — modern farmhouse editorial with farmers-market energy.

- Palette: warm cream (`#FBF4E4`), terracotta accent (`#B8431A`), forest green (`#3A5A3E`)
- Typography: Newsreader (serif headlines) + DM Sans (body) + JetBrains Mono (labels)
- Tone: warm, editorial, no cool grays

## Screens

| Route              | Description            |
| ------------------ | ---------------------- |
| `/`                | Desktop landing page   |
| `/mobile/home`     | Mobile discovery feed  |
| `/mobile/dish`     | Mobile dish detail     |
| `/mobile/profile`  | Mobile cook profile    |

## Running Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173` (or next available port).

## Tech Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- React Router v7

## Build

```bash
npm run build
npm run preview
```
